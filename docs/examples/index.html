    Complete examples¶

    These synthetic fonts contain A (U+0041) and a metric-only space (U+0020). They are original examples under the repository's MIT license. No private font or implementation is included. Each listing below comes from the downloadable file itself.

    Example Image representation Storage Scaled advance of A
    Embedded PNG Transparent 1×1 PNG, PPM 100 MIME/Base64 600 font units
    External PNG Same PNG pixel.png 600 font units
    Embedded SVG Red stylized A, PPM 1000 SVG fragment 650 font units
    External SVG Same visible geometry A.svg 650 font units

    All four use UPM 1000 and a 250-unit space advance. The tiny PNG demonstrates transport and metrics; it is transparent and is not intended as a visible letter. The SVG examples put their top 700 units above the baseline. Their horizontal shape positions match despite their different source coordinate systems.

    Embedded PNG¶

    Download embedded-png.phf. No additional files are needed. PNG data is wrapped in MIME headers inside data/photo/image.

    <?xml version='1.0' encoding='utf-8'?>
<PhF version="2.0">
  <!-- this_file: src_docs/md/examples/embedded-png.phf -->
  <header>
    <family type="string">Example Colour</family>
    <upm type="int">1000</upm>
    <ascender type="int">800</ascender>
    <descender type="int">200</descender>
  </header>
  <globals>
    <unicode_mapping type="array" subtype="map_unicode">
      <map id="A" unc="65" />
      <map id="space" unc="32" />
    </unicode_mapping>
  </globals>
  <glyphs>
    <glyph id="A">
      <image id="v0" type="photo">
        <shape embedded="pixel">
          <ppm int="100" />
          <bbox x="0" y="0" width="1" height="1" />
          <base x="0" y="1" />
          <delta x="60" y="0" />
        </shape>
      </image>
    </glyph>
    <glyph id="space">
      <image id="v0" type="photo">
        <shape>
          <ppm int="1000" />
          <bbox x="0" y="0" width="0" height="0" />
          <base x="0" y="0" />
          <delta x="250" y="0" />
        </shape>
      </image>
    </glyph>
  </glyphs>
  <data>
    <photo>
      <image id="pixel">
Content-Type: image/png
Content-transfer-encoding: base64

iVBORw0KGgoAAAANSUhEUgAAAAEAAAABCAYAAAAfFcSJAAAAC0lEQVR4nGNgAAIA
AAUAAXpeqz8AAAAASUVORK5CYII=
</image>
    </photo>
  </data>
</PhF>

    Embedded SVG¶

    Download embedded-svg.phf. The glyph references an SVG fragment in data/image; no nested SVG root or MIME wrapper is used.

    <?xml version='1.0' encoding='utf-8'?>
<PhF version="2.0">
  <!-- this_file: src_docs/md/examples/embedded-svg.phf -->
  <header>
    <family type="string">Example Colour</family>
    <upm type="int">1000</upm>
    <ascender type="int">800</ascender>
    <descender type="int">200</descender>
  </header>
  <globals>
    <unicode_mapping type="array" subtype="map_unicode">
      <map id="A" unc="65" />
      <map id="space" unc="32" />
    </unicode_mapping>
  </globals>
  <glyphs>
    <glyph id="A">
      <image id="v0" type="svg">
        <shape embedded="a-vector">
          <ppm int="1000" />
          <delta x="650" y="0" />
        </shape>
      </image>
    </glyph>
    <glyph id="space">
      <image id="v0" type="photo">
        <shape>
          <ppm int="1000" />
          <bbox x="0" y="0" width="0" height="0" />
          <base x="0" y="0" />
          <delta x="250" y="0" />
        </shape>
      </image>
    </glyph>
  </glyphs>
  <data>
    <image id="a-vector" type="svg">
      <g xmlns="http://www.w3.org/2000/svg" fill="#d13b42">
        <path d="M0 0 L300 -700 L600 0 L450 0 L300 -400 L150 0 Z" />
      </g>
    </image>
  </data>
</PhF>

    External SVG¶

    Save external-svg.phf and A.svg in the same directory. The external image's baseline is at y=700.

    <?xml version='1.0' encoding='utf-8'?>
<PhF version="2.0">
  <!-- this_file: src_docs/md/examples/external-svg.phf -->
  <header>
    <family type="string">Example Colour</family>
    <upm type="int">1000</upm>
    <ascender type="int">800</ascender>
    <descender type="int">200</descender>
  </header>
  <globals>
    <unicode_mapping type="array" subtype="map_unicode">
      <map id="A" unc="65" />
      <map id="space" unc="32" />
    </unicode_mapping>
  </globals>
  <glyphs>
    <glyph id="A">
      <image id="v0" type="svg">
        <shape system="A.svg">
          <ppm int="1000" />
          <base x="0" y="700" />
          <delta x="650" y="0" />
        </shape>
      </image>
    </glyph>
    <glyph id="space">
      <image id="v0" type="photo">
        <shape>
          <ppm int="1000" />
          <bbox x="0" y="0" width="0" height="0" />
          <base x="0" y="0" />
          <delta x="250" y="0" />
        </shape>
      </image>
    </glyph>
  </glyphs>
</PhF>

    The SVG resource is a standalone document:

    <?xml version="1.0" encoding="UTF-8"?>
<!-- this_file: src_docs/md/examples/A.svg -->
<svg xmlns="http://www.w3.org/2000/svg" width="600" height="700" viewBox="0 0 600 700">
  <path d="M0 700 L300 0 L600 700 L450 700 L300 300 L150 700 Z" fill="#d13b42"/>
</svg>

    Inspect the files¶

    Download photofont.py, then run:

    uv run photofont.py embedded-png.phf
uv run photofont.py external-svg.phf
uv run photofont.py --write new-demo.phf
uv run photofont.py new-demo.phf

    The writer creates a new file and refuses to overwrite an existing one. See Python recipes for the reader's scope and resource extraction.
